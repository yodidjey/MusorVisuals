# MusorVisuals 🎨

**Профессиональный визуальный мод для Minecraft 1.21.1**

Superior visual modification combining the best features from ReallyVisuals, PulseVisuals, and AuraVisuals.

## 🌟 Особенности

### 🌍 Окружение и Атмосфера
- ✨ Ambience / TimeChanger - изменение времени суток
- 🌧️ Weather Modifier - отключение осадков
- 🌫️ Custom Fog - настройка тумана
- 🌌 Custom Stars & Moon - кастомизация неба
- 🎨 World Tint - тонирование мира
- 💨 Motion Blur - эффект размытия

### 👥 Отображение Сущностей
- 📦 Entity ESP (2D/3D боксы)
- 👻 Chams (модели сквозь стены)
- 🎯 Tracers (линии к сущностям)
- 💀 Skeleton ESP
- ✨ Glow ESP
- 📝 NameTags (расширенные плашки)

### ✨ Частицы и Эффекты
- 🎩 China Hat
- 🍞 Breadcrumbs (следы)
- ⭕ Jump Circles
- 🦅 Wings (крылья)
- 💫 Particles
- 🌀 Target Particles

### 🖥️ HUD и Интерфейс
- 🎯 Target HUD (панель цели)
- 🏷️ Watermark (логотип)
- 📊 ArrayList (список модулей)
- 🛡️ Armor HUD
- 📡 Radar (миникарта)
- 🔔 Notifications

### 🎮 Камера и Эффекты
- 🎥 Freecam
- 📐 Aspect Ratio
- ✋ Hand Modifier
- 💥 Hitmarkers
- ☀️ Fullbright
- ❌ NoRender

## 🛠️ Требования

- Minecraft 1.21.1
- Fabric Loader 0.15.11+
- Java 21+

## 📦 Установка

1. Скачайте Fabric Loader
2. Скачайте Fabric API
3. Поместите MusorVisuals.jar в папку mods
4. Запустите Minecraft

## ⚙️ Конфигурация

Конфигурация сохраняется в `~/.minecraft/config/MusorVisuals/config.json`

## 🎨 Стиль ClickGUI

- **Цвет**: Фиолетовый (#7700FF)
- **Стиль**: Карточки с анимацией
- **Шрифт**: EspressoDolce-подобный
- **Элементы**: Кнопки, слайдеры, переключатели
